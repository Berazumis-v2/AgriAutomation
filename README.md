# AgriAutomation

## Projekto pavadinimas: Išmanioji Sodininkystės Sistema

Sprendžiamo uždavinio aprašymas: Projektas sprendžia augalų priežiūros problemą, siekiant efektyviai valdyti laistymo, drėgmės ir temperatūros sąlygas remiantis sensorių duomenimis bei augalų poreikiais. Tikslas yra sukurti sistemą, kuri optimizuotų augalų augimo sąlygas, sumažintų žmogaus įsikišimą ir padidintų sodininkystės veiklos efektyvumą.

Sistemos paskirtis: Sistema skirta automatizuoti augalų laistymą ir temperatūros kontrolę, remiantis sensorių surinktais duomenimis. Sistema suteikia galimybę stebėti augalų būklę realiu laiku, atlikti automatizuotą laistymo ir apšvietimo valdymą pagal individualius augalų poreikius, bei generuoti statistines ataskaitas apie augimo duomenis.


## Funkciniai reikalavimai: 

 • Sensorių duomenų surinkimas (drėgmės, temperatūros) ir jų analizė. 

 • Automatizuota laistymo sistema, valdoma pagal realaus laiko duomenis ir augalų poreikius.  

 • API, kuri leidžia gauti realaus laiko informaciją apie augalų būklę. 

 • Statistinės analizės įrankiai, generuojantys ataskaitas apie augalų augimo procesus.
